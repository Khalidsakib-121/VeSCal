# Source data

`vegetation_reference.csv` is the 1,833-row, eight-predictor reference table bundled with the frozen corrected implementation. Original source: Falco et al., *Vegetation classification map and covariates associated with NEON AOP survey, East River, CO 2018*, ESS-DIVE, DOI: https://doi.org/10.15485/1602034.

This file contains reference-location coordinates, fine-class labels, source metadata and covariates. The training script uses the equivalent copy stored in `vescal/data/` by default. Consult the original dataset's use/attribution requirements before public redistribution. This publication-ready draft includes the data for reproducibility but does not assert a new license for the original dataset. Its observed structure was not transformed or anonymized.
